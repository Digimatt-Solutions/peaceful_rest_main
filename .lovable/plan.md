# Refine the Makiwa landing page

## Direction
Use the selected modern organic direction with Makiwa’s Paper & Ink palette, Quicksand body text, refined Cormorant headings, restrained orange accents, and the current section order.

## Changes
- Refine the navigation and opening section with calmer proportions, fine-line details, subtle dot patterns, and a more polished memorial carousel.
- Restyle memorial cards, search, pagination, and service content with consistent edges, restrained shadows, stable image proportions, and accessible controls.
- Create visual rhythm between sections using warm paper surfaces, thin dividers, subtle grain, organic corner shapes, and alternating editorial compositions.
- Simplify the Why Makiwa collage, dark process section, banner, and footer so imagery stays prominent and decoration remains secondary.
- Keep all current data loading, navigation, search, sharing, authentication links, and other behavior unchanged.

## Quality checks
- Check desktop and mobile layouts for overlaps, clipping, spacing, and readable contrast.
- Verify reduced-motion behavior, lazy-loaded imagery, interactive states, and a clean build.
